# FUNDING.yml - Sponsor Button

## Rule
Add `FUNDING.yml` for open source repos to show a "Sponsor" button.

## Code
```yaml
# .github/FUNDING.yml

# GitHub Sponsors
github: [your-username]

# Other platforms
patreon: your-patreon-username
buy_me_a_coffee: your-username
ko_fi: your-username
open_collective: your-project
custom: ["https://your-donation-link.com"]
```

## Result
Adds a "Sponsor" button at the top of the repo page with links to all configured platforms.

## Why
Many open source developers don't know this exists. It's a free way to enable financial support for your project. Takes 30 seconds to set up.
