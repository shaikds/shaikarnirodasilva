# Saved Replies

## Rule
Set up Saved Replies for common code review comments to save time.

## Setup
```
GitHub Settings -> Saved replies -> Add a saved reply
```

## Recommended Replies

### Needs Tests
```
Thanks for the PR! Could you please add unit tests for this change?
Our coverage threshold requires at least 80% for new code.
```

### LGTM
```
LGTM! Great work. Approving.
```

### Minor Suggestion (non-blocking)
```
Minor suggestion (non-blocking): Consider using X instead of Y for better readability.
Feel free to address in a follow-up PR if you prefer.
```

### Needs Documentation
```
This change introduces new behavior - could you update the docs/README to reflect this?
```

### Stale Issue
```
This issue has been inactive for 30 days. Closing due to inactivity.
Feel free to reopen if this is still relevant.
```

### Duplicate
```
This appears to be a duplicate of #XXX. Closing in favor of the existing issue.
Please add any additional context to the original issue.
```

## Keyboard Shortcut
`Ctrl+.` (or `Cmd+.` on Mac) inside any GitHub comment box opens saved replies.

## Why
Code review comments often repeat. Saved replies maintain consistency and save typing time. The keyboard shortcut makes them instant to use.
