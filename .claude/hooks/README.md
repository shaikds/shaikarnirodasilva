# .claude/hooks — הבלם האוטומטי

הסוכן `consistency-checker` *מדווח* על סטיות, אבל סוכן יכול לטעות.
הבלם ה**קשיח** הוא hook: סקריפט דטרמיניסטי שהharness מריץ אוטומטית,
ושיכול לעצור את התהליך בלי תלות בשיקול דעת של AI.

## איך מחווטים

הקובץ `guardrail.sh` הוא תבנית. ערוך אותו כך שיריץ את הבדיקות
האמיתיות של הפרויקט (טסטים, linter, type-check), ואז רשום אותו
כ-hook ב-`.claude/settings.json`. דוגמה:

```json
{
  "hooks": {
    "Stop": [
      {
        "matcher": "",
        "hooks": [
          { "type": "command", "command": ".claude/hooks/guardrail.sh" }
        ]
      }
    ]
  }
}
```

הוק שמחזיר exit code שונה מ-0 חוסם — בדיוק כמו "הסוכן שעוצר את התהליך".
אפשר לחווט גם ל-`PostToolUse` (אחרי כל עריכת קובץ) — בחר לפי קצב העבודה.

## למה דווקא סקריפט ולא סוכן

טסט שנכשל הוא עובדה, לא דעה. בלם דטרמיניסטי לא מתעייף, לא "מרחם",
ולא משכנעים אותו. את שיקול הדעת משאירים לסוכנים; את ה-pass/fail —
לסקריפט.
