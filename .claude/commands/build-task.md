מימוש המשימה: **$ARGUMENTS**

בצע את הלולאה לפי `CLAUDE.md`:

1. מצא את המשימה באפיון תחת `docs/02-modules/`. אם אין אפיון — עצור והפעל קודם `/new-feature`.
2. ודא שאתה על branch ייעודי למשימה (`feat/...` או `fix/...`). אם לא — צור אותו.
3. ממש **רק** את המשימה הזו. לא יותר. אל תיגע במה שמוגדר "מחוץ לסקופ".
4. הפעל את הסוכן `code-reviewer`. אם יש חוסמים — תקן וחזור לשלב הזה.
5. הפעל את הסוכן `qa-tester`. אם בדיקה נכשלת — תקן וחזור לשלב 4.
6. סכם מה מומש, מול אילו כללים (L), ומה מצב הבדיקות. אל תעשה commit — לזה יש `/ship`.
