# טמפלייט אייג'נט אוטו-ריסרץ' לשיווק ומודעות

תבנית להקמת **אייג'נט שיווק נפרד לכל עסק**, שמנהל מודעות בנפרד לכל פלטפורמה
(Meta / Instagram / Google / TikTok) **ומשתפר מעצמו** באמצעות זיכרון תובנות שגדל מניסוי לניסוי.

המדריך המלא, כולל הסבר על כל בחירת עיצוב ומטריקה: [`docs/index.html`](../docs/index.html)

## הרעיון בשלוש שורות

1. **עסק = תיקייה.** משכפלים את התיקייה הזו לכל עסק; לכל עסק זיכרון והחלטות משלו, בלי זליגה בין עסקים.
2. **פלטפורמה = מודול.** לכל פלטפורמה קובץ משלה עם מדדים, עץ אבחון ורף ייחוס משלה — כי CTR "טוב" בגוגל הוא פי 4 מטיקטוק.
3. **שיפור עצמי = זיכרון.** כל ריצה שבועית מסתיימת בעדכון `memory/insights.md`; הריצה הבאה מתחילה מקריאתו. ככה האייג'נט של כל עסק לומד את העסק הספציפי הזה.

## מבנה

```
marketing-agent-template/
├── AGENT.md                       ← הוראות האייג'נט: סדר קריאה, הלולאה השבועית, כללי בטיחות
├── business-profile.md            ← הקובץ היחיד שממלאים ידנית (פעם אחת)
├── platforms/
│   ├── meta.md                    ← מדדים, עץ אבחון וניסויים — פייסבוק
│   ├── instagram.md               ← נפרד ממטא: Reels, Hook Rate, מובייל בלבד
│   ├── google.md                  ← חיפוש: Intent, Quality Score, מילים שליליות
│   └── tiktok.md                  ← קריאייטיב-קודם, שחיקה מהירה, Spark Ads
├── memory/
│   ├── insights.md                ← מנגנון ההשתפרות: תובנות מצטברות פר-עסק
│   ├── experiments-log.md         ← יומן ניסויים: משתנה אחד, מדד אחד, דדליין
│   ├── weekly-report-template.md  ← פורמט הדוח השבועי
│   └── reports/                   ← נוצר בריצה הראשונה: דוח לכל שבוע
└── metrics/
    └── kpi-definitions.md         ← הגדרות מדדים לפי שלבי משפך + בנצ'מארקים 2026
```

## התחלה מהירה

```bash
# עסק חדש = עותק חדש של התבנית
cp -r marketing-agent-template businesses/acme-dental
```

1. ממלאים את `businesses/acme-dental/business-profile.md` (10 דקות; חובה למלא את כלכלת היחידה).
2. פותחים סשן של Claude (או כל LLM אחר) על תיקיית העסק עם ההנחיה: **"פעל לפי AGENT.md — ריצה שבועית"**, ומצרפים ייצוא נתונים מהפלטפורמות.
3. האייג'נט מחזיר דוח שבועי, פותח ניסוי אחד לכל פלטפורמה, ומעדכן את הזיכרון.
4. חוזרים על שלב 2–3 כל שבוע. אחרי 4–6 שבועות ההשוואות עוברות מבנצ'מארק ענפי לעבר האמיתי של העסק — מרגע זה השיפור מונע מהדאטה של העסק עצמו.
