# Client Onboarding Checklist

Complete each step in order when bringing on a new client.

---

## Phase 1: Discovery & Qualification
- [ ] Schedule discovery call
- [ ] Fill [CLIENT_DISCOVERY.md](CLIENT_DISCOVERY.md) during call
- [ ] Determine service type (AI Agents / No-Code→Prod / Custom Dev / Retainer)
- [ ] Assess if project is a good fit (budget, timeline, complexity)
- [ ] Request access to existing system (if applicable)

## Phase 2: Technical Assessment
- [ ] If No-Code→Production: Complete [TECHNICAL_ASSESSMENT.md](TECHNICAL_ASSESSMENT.md)
- [ ] If AI/Automation: Define agent requirements and data sources
- [ ] If Custom Dev: Create architecture sketch
- [ ] Identify technical risks and unknowns
- [ ] Estimate effort using [ESTIMATION_FRAMEWORK.md](../estimation/ESTIMATION_FRAMEWORK.md)

## Phase 3: Proposal & Contract
- [ ] Prepare proposal using [PROPOSAL_TEMPLATE.md](../contracts/PROPOSAL_TEMPLATE.md)
- [ ] Include timeline, milestones, and pricing
- [ ] Send proposal to client
- [ ] Address client questions/negotiate if needed
- [ ] Prepare SLA using [SLA_TEMPLATE.md](../contracts/SLA_TEMPLATE.md)
- [ ] Get signed agreement
- [ ] Receive first payment (50% upfront or first milestone)

## Phase 4: Project Setup
- [ ] Follow [CLIENT_PROJECT_SETUP.md](../processes/CLIENT_PROJECT_SETUP.md):
  - [ ] Create GitHub repository: `client-{name}-{project}`
  - [ ] Copy client-project-template
  - [ ] Set up branch protection rules
  - [ ] Configure CI/CD pipeline
  - [ ] Set up environment variables
  - [ ] Create project board (Kanban)
- [ ] Create V1.0 milestone with issues
- [ ] Set up communication channel with client (Slack/WhatsApp group)

## Phase 5: Kickoff
- [ ] Schedule kickoff meeting with client
- [ ] Walk through timeline and milestones
- [ ] Confirm communication preferences
- [ ] Share staging URL (when available)
- [ ] Confirm first sprint goals
- [ ] Start development!

## Phase 6: Ongoing
- [ ] Send weekly updates using [WEEKLY_STATUS_REPORT.md](../processes/WEEKLY_STATUS_REPORT.md)
- [ ] Demo progress at milestones
- [ ] Get milestone approval before proceeding

## Phase 7: Delivery
- [ ] Follow [PROJECT_CLOSEOUT.md](../contracts/PROJECT_CLOSEOUT.md)
- [ ] Deliver final product
- [ ] Transfer credentials and documentation
- [ ] Collect final payment
- [ ] Discuss ongoing maintenance (retainer opportunity)
- [ ] Request testimonial/review
