  headless Chromium uses SwiftShader software rendering; real 60 fps (AC-4.6.6)
  is verified on hardware evidence at P7/P8. p0 spec amended accordingly.

- **Verification:** p1_movement 14/14 PASS (camera-relative W, jump apex,

  Pattern documented in the spec file for all future combat tests. Also made
  test reset() wipe combo/hitstop state — hitstop pauses sim time, so combo
  windows outlive wall-clock expectations.
