  Pattern documented in the spec file for all future combat tests. Also made
  test reset() wipe combo/hitstop state — hitstop pauses sim time, so combo
  windows outlive wall-clock expectations.
- **Bug found by test:** DummyBrain in idle mode force-releases externally
  set blocks — tests must drive the brain, not the fighter.
- **Verification:** p2_combat 20/20 PASS ×3 consecutive runs (string chain
  light1→2→3 with zero idle gaps, combo math 6.00/7.56/11.60, blocked heavy

  lock drop). p0, p1 regressions PASS.

## P3 closed — The rival fights (profile, sync, micro-GOAP, special)
- Built: `ai/playerProfile.js` (ported profile + Profiler that observes
  Fighter actions/events — works identically for human input and bot
  drivers); `ai/syncEngine.js` (ported ELO rating→skill); `ai/goap.js`
  (generic A* planner, maxDepth + costNoise as the skill model);
  `ai/microActions.js` (9 actions / 5 goals as data; profile-derived costs
  are the mirror); `ai/rivalAgent.js` (reactive defense mirroring the
  player's defenseRate/reaction/dodgePref, plan-execute loop, rubber band,
  mistakes model, comboFollowup pressure mirror, goal exposure for HUD);
  `combat/projectiles.js` (aimed-at-fire-time specials through the same
  Resolver rulebook); `ai/bots.js` (aggressive/turtle/heavyOnly test
  doubles); fighter separation; swappable player driver + `step(n)` manual
  stepping exposed for tests.
- **Balance findings (band test drove design):** first band run was 9:1 for
  the player — the rival had dead time between plans and never pressed after
  landing hits. Fixes: idle+no-plan ⇒ replan immediately (replanT is max
  staleness, not a gate) and comboFollowup-mirrored pressure. Band then
  landed 4:6 and 5:5 with the rating visibly oscillating (848–1037) —
  the sync engine doing its job.
- **Test decomposition decision:** AC-3.3.2 split into (a) *learning* —
  3 heavy-only duels ⇒ profile heavyPref ≥0.8 — and (b) *mirroring* —
  profiler frozen, forced light-vs-heavy profiles ⇒ ≥20 pt behavior shift —
  because live learning converges within a single duel, leaving no
  measurable "baseline" duel. Spec status table annotated.
- **Verification:** p3_rival 13/13 PASS ×2 (GOAP chains + depth limit, skill
  endpoints, special 18/9/cost, BreakGuard ≥70% heavies vs turtle, learning,
  mirroring, S-3 band 4:6 then 5:5, goal exposure). p0/p1/p2 regressions
  PASS.
