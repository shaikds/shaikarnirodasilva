# Sample files

`files/CLAUDE.md` is a rule of about 1,000 tokens (about 4,000 characters; `/inspect` shows its exact range).
It loads when Claude reads a file from this folder. Send any of these to see it at work:

- `notes.txt` - plain text
- `sales.csv` - table
- `report.pdf` - 2-page PDF
- `chart.png` - image

Every answer ends with `FILES-RULE-ACTIVE` when the rule is in the context.
